# Counter App

A simple counter application developed in React and CSS as a study project. The goal is to allow users to increment, decrement, and reset a count, with an interface adapted for both desktop and mobile devices.

## Features

* Dynamic counting: buttons to increase, decrease, and reset the value to zero.
* Visual feedback: The color of the number changes depending on whether the value is positive (green), negative (red), or zero (white).
* Mobile optimization: Responsive layout with quick-tap buttons, accidental zoom prevention, and text selection prevention when clicking multiple times in a row.

## Technologies Used

* React 
* Vite
* CSS 

## How to run the project locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Navigate to the project folder:
   ```bash
   cd repository-name
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the URL shown in the terminal (usually `http://localhost:5173`) in your browser.
